## Objetivos de Aprendizagem

Ao final desta matéria, o aluno deverá ser capaz de:

<Steps>

1. Utilizar funções lógicas (`SE`, `E`, `OU`) para tratamento de dados.

2. Realizar buscas de dados eficientes com `PROCV`, `ÍNDICE` e `CORRESP` (e `XLOOKUP`).

3. Criar Tabelas Dinâmicas (Pivot Tables) para resumir grandes volumes de dados.

4. Compreender a importância de **Dados Estruturados** e integridade da informação ("Garbage In, Garbage Out").

5. Construir gráficos claros para apresentação de resultados.

6. Aplicar **Validação de Dados** para prevenir erros de entrada.

</Steps>

## Tópicos Abordados

-   **Tratamento de Dados**: Limpeza de texto, datas e formatação condicional.
-   **Fórmulas Essenciais**: Soma, Contagem, Médias condicionais (`SOMASE`, `CONT.SE`).
-   **Busca e Referência**: Cruzando tabelas diferentes.
-   **Análise Dinâmica**: Pivot Tables e Pivot Charts.
-   **Validação de Dados**: Prevenindo "Garbage In" com regras de entrada.

### Fundamentos de Dados

-   **Estrutura de Dados**: Diferença entre dados estruturados (tabelas) e não estruturados.
-   **Modelagem Básica em Planilhas**:
    -   Colunas como Atributos, Linhas como Registros.
    -   Conceito de Chaves (Identificadores únicos) para cruzar tabelas (`PROCV`).
-   **Integridade**: Garantindo que números sejam números e datas sejam datas.
